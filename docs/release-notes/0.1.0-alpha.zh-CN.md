# YinShield 0.1.0-alpha

[English](./0.1.0-alpha.md) | 简体中文

## 概要

`0.1.0-alpha` 是 YinShield 的第一个公开 alpha 版本。

这个版本把项目从一个脱敏 demo 推进成一个本地优先的隐私层原型，当前包含：
- Python 包 + CLI
- 本地 HTTP bridge
- OpenAI-compatible wrapper
- OpenClaw 薄插件
- 支持会话一致性的可逆脱敏
- `placeholder` 和 `alias` 两种模式
- 中英高频 PII 支持

当前建议定位：
- 本地单用户部署
- 开发者接入验证
- OpenClaw 集成试用
- `placeholder` 模式作为当前最稳的生产近似默认项

## 本次包含内容

- 面向中英 PII 的核心脱敏引擎
- `mode="placeholder"` 和 `mode="alias"`
- `strategy="loose" | "balanced" | "strict"`
- 用于多轮稳定替换的会话持久化
- `ShieldedOpenAI` 和 `ShieldedAsyncOpenAI`
- 通过 `yinshield serve` 提供的本地 HTTP 服务
- OpenClaw 插件：`@serein-213/openclaw-yinshield`

当前 alpha 已支持的实体包括：
- 中文姓名与英文姓名
- 中国手机号与 US phone
- 中国身份证与 US SSN
- 邮箱与微信号
- 中文地址与英文街道地址
- 公司名
- 税务标识，包括统一社会信用代码与 EIN
- 银行账号相关字段
- VIN / 护照 / 车牌 / IP 地址
- 病历号以及订单 / 快递 / 业务编号类字段

## Benchmark

Sample set benchmark：
- `placeholder + strict`: `precision=1.0 recall=1.0 false_positive_rate=0.0 recovery_rate=1.0 semantic_proxy=0.3662`
- `alias + strict`: `precision=1.0 recall=1.0 false_positive_rate=0.0 recovery_rate=1.0 semantic_proxy=0.8182`

Mini realistic set benchmark：
- `placeholder + strict`: `precision=0.9765 recall=0.9765 false_positive_rate=0.0645 recovery_rate=1.0 semantic_proxy=0.321`
- `alias + strict`: `precision=0.9425 recall=0.9647 false_positive_rate=0.1613 recovery_rate=0.9355 semantic_proxy=0.75`

当前可这样理解：
- `placeholder` 目前是最稳的模式
- `alias` 在很多情况下更保留语义，但在更真实、英文占比更高的数据上仍有更多边界情况
- `semantic_proxy` 只是本地格式保留启发式指标，不是端到端 LLM 任务质量 benchmark

## 安装

Python 包：

```bash
pip install yinshield
```

OpenClaw 路径：

```bash
pip install yinshield
python -m yinshield.install_openclaw
openclaw plugins install @serein-213/openclaw-yinshield
openclaw plugins enable openclaw-yinshield
yinshield serve
```

## 已知限制

- 在更真实的英文公司名 / 地址场景下，`alias` 模式还没有 `placeholder` 稳定
- HTTP 服务当前面向本地单用户使用，不是多租户部署形态
- 打包与所有 OpenClaw 运行时组合的实时 e2e 覆盖仍不完整
- 当前版本仍以规则与上下文辅助为主，不是完整语义 NER 系统

## 对 0.1.0-alpha 的推荐用法

- 如果你想要当前最安全的默认项，优先使用 `mode="placeholder"`
- 如果你更看重语义保留，并且可以接受 alpha 级边界情况，再使用 `mode="alias"`
- 将 HTTP 服务绑定在 `127.0.0.1`
- 为本地 bridge 启用 auth token
