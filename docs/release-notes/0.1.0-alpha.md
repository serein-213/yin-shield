# YinShield 0.1.0-alpha

English | [简体中文](./0.1.0-alpha.zh-CN.md)

## Summary

`0.1.0-alpha` is the first public alpha for YinShield.

This release turns the project from a masking demo into a local-first privacy layer prototype with:
- Python package + CLI
- local HTTP bridge
- OpenAI-compatible wrapper
- OpenClaw thin plugin
- reversible masking with session consistency
- `placeholder` and `alias` modes
- Chinese and English high-frequency PII support

Current recommended positioning:
- local single-user deployment
- developer integration validation
- OpenClaw integration trial
- `placeholder` mode for the most stable production-like behavior

## What Is Included

- Core masking engine for Chinese and English PII
- `mode="placeholder"` and `mode="alias"`
- `strategy="loose" | "balanced" | "strict"`
- session persistence for stable multi-turn replacements
- `ShieldedOpenAI` and `ShieldedAsyncOpenAI`
- local HTTP service via `yinshield serve`
- OpenClaw plugin: `@serein-213/openclaw-yinshield`

Supported entities in this alpha include:
- Chinese names and English names
- China mobile phone numbers and US phone numbers
- Chinese ID cards and US SSN
- email and WeChat IDs
- Chinese addresses and English street addresses
- company names
- tax identifiers including unified social credit code and EIN
- bank account fields
- VIN / passport / license plate / IP address
- medical record numbers and tracking/order-style identifiers

## Benchmarks

Sample-set benchmark:
- `placeholder + strict`: `precision=1.0 recall=1.0 false_positive_rate=0.0 recovery_rate=1.0 semantic_proxy=0.3662`
- `alias + strict`: `precision=1.0 recall=1.0 false_positive_rate=0.0 recovery_rate=1.0 semantic_proxy=0.8182`

Mini realistic-set benchmark:
- `placeholder + strict`: `precision=0.9765 recall=0.9765 false_positive_rate=0.0645 recovery_rate=1.0 semantic_proxy=0.321`
- `alias + strict`: `precision=0.9425 recall=0.9647 false_positive_rate=0.1613 recovery_rate=0.9355 semantic_proxy=0.75`

Interpretation:
- `placeholder` is currently the most stable mode.
- `alias` preserves semantics better in many cases, but still has more edge cases on realistic English-heavy data.
- `semantic_proxy` is only a local format-preservation heuristic, not an end-task LLM quality benchmark.

## Installation

Python package:

```bash
pip install yinshield
```

OpenClaw path:

```bash
pip install yinshield
python -m yinshield.install_openclaw
openclaw plugins install @serein-213/openclaw-yinshield
openclaw plugins enable openclaw-yinshield
yinshield serve
```

## Known Limitations

- `alias` mode is not yet as stable as `placeholder` on realistic English company/address cases.
- HTTP service is designed for local single-user use, not multi-tenant deployment.
- There is still no full live e2e coverage for packaging and every OpenClaw runtime combination.
- This release is rule-heavy and context-assisted, not a full semantic NER system.

## Recommended Usage For 0.1.0-alpha

- Prefer `mode="placeholder"` if you want the safest current default.
- Use `mode="alias"` when semantic preservation matters more and you can tolerate alpha-level edge cases.
- Keep the HTTP service bound to `127.0.0.1`.
- Use auth tokens for the local bridge.
